# Tonight is for you ♡

A complete mobile-first surprise in HTML, CSS and vanilla JavaScript. No build or packages required.

## Personalise

Edit `config.js`: change girlfriendName, senderName, letter paragraphs and reasons. Put your two photos in `assets/`, then enter paths such as `assets/us.jpg` in the photos array. Blank paths show intentional photo placeholders. Update photoDescriptions for accessible descriptions. No photos or personal details are uploaded anywhere.

## Open

Run `node server.cjs` in this folder and open http://127.0.0.1:4173. Stop with Ctrl+C. You can also open index.html directly. The local address works on this computer only; a publicly hosted copy is needed to send her a link remotely.

## Files

- index.html: sections and visible text
- styles.css: colours, responsive layout and animations
- config.js: names, photos, letter and reasons
- script.js: interactions, particles and original synthesised music
- server.cjs: small local preview server

Sound is off by default and starts only after a button tap. The website respects reduced-motion preferences. Fonts use Google Fonts with built-in fallbacks; everything else works offline. The “still angry” answer stays available and never runs away. October 1 is your personal celebration, without claiming an official holiday.
